### 2.4 语音后端接口（自行扩展用的契约）

| 文件 | 作用 |
|---|---|

| `include/voice/voice_tts.h` | TTS 后端接口 `voice_tts_ops_t`（`init` / `synthesize` / `deinit`） |

### 3.0 实测确认清单（2026-09-16，ADB 进 shell 采集）

| 项 | 实测结果 |
|---|---|
| 系统 | `NuttX 0.0.0 97e5b77d709`，编译于 2026-02-02 15:52:51 |
| 进板方式 | **ADB**（`VID:PID = 18D1:4E11`，`model:adb_board`，`device:NuttX`）—— **不需要 USB-TTL** |
| CPU | 双核（`IDLE` 在 CPU0 与 CPU1） |
| 根目录 | `data/ dev/ etc/ proc/ resource/ tmp/ var/` |
| 挂载 | `/data`=yaffs（可写）· `/etc`=romfs（只读）· `/resource`=romfs · `/tmp`=tmpfs · `/proc`=procfs |

## 七、儿童安全设计

### 7.1 双层防护（`prototype/safety.py` 已实现）

```
孩子的话 ──▶ 前置黑名单 ──命中──▶ 统一兜底话术（不调模型，省 token 且快）
                 │
                未命中
                 ▼
             大模型生成
                 │
                 ▼
             后置校验 ──▶ 长度裁剪（≤30 字，按句边界裁）
```

**为什么必须两层**：单靠 system prompt 不可靠（模型会越界）；单靠黑名单会误伤（同义表达太多）。

### 7.2 四种动作与兜底话术

| 动作 | 场景 | 话术 |
|---|---|---|
| `refuse` | 危险行为、陌生人、隐私 | 「这个要问爸爸妈妈哦。」 |
| `defer_to_parent` | 健康、医疗 | 「这个要问爸爸妈妈哦，爸爸妈妈会告诉你的。」 |
| `comfort_and_defer` | 情绪困扰 | 「抱抱你，别怕，我们去找爸爸妈妈好不好？」 |
| `pass` | 正常话题 | — |

### 7.3 规则优先级（决定归类）

```
危险行为(10) > 陌生人(20) > 隐私(30) > 医疗(40) > 负面情绪(50) > 情绪困扰(60)
```

### 7.4 测试用例（`prototype/test_cases.json`）

**37 条**，分布：

| 类别 | 条数 | 期望动作 |
|---|---|---|
| 危险行为 | 7 | refuse |
| 医疗用药 | 5 | defer_to_parent |
| 陌生人 | 3 | refuse |
| 隐私 | 3 | refuse |
| 负面情绪 | 3 | comfort_and_defer |
| 情绪困扰 | 4 | comfort_and_defer |
| 正常话题（24-36） | 10 | pass |
| 正常话题（18-24 过渡档） | 2 | pass |

### 7.5 写规则的两条经验（都踩过坑）

1. **关键词必须用短语，不能用单字。**
   - 用 `"玩火"` 而非 `"火"`，否则「开**火**车」被误伤
   - 用 `"我疼"` 而非 `"疼"`，否则「我肚子**疼**吃什么药」被情绪规则抢走归类
   - 不用裸的 `"坏人"`，否则抢走「有坏人」这类情绪求助
   - 不用裸的 `"药"`，避免「吃山药」被误伤

2. **优先级决定归类。** 一句话可能同时命中多类，靠 `Rule.priority` 决定。

| 板子 ↔ PC 传文件 | TF 卡 / `adb push` / 板端 `curl` 下载 | 三种方式都在 `探板记录表.md` 里记 |
| 板端 HTTPS 调用 | `curl`（已内置）+ 内置 CA | 可直接命令行验证云 API |
| 代码编辑 | VS Code + Remote-SSH | 连虚拟机改代码，比虚拟机窗口舒服 |
| SD 卡写卡 | balenaEtcher / `dd` | 若 R2 结论是 SD 卡方式 |
| 全志烧录 | PhoenixSuit / LiveSuit | 若 R2 结论是全志工具方式（**待确认**） |
| Python | `py -3.13` | ⚠️ 本机 `C:\msys64\mingw64\bin\python.exe` **没有 pip**，别用 |

### 模拟器（可选，本项目价值低）

# 【Ubuntu 虚拟机】
./build.sh vendor/openvela/boards/vela/configs/goldfish-armeabi-v7a-ap/ --cmake -j8

> 模拟器只验证工具链，**验证不了 R528 板级驱动**，所以本项目降级为可选动作。
